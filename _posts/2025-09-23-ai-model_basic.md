## 线性回归 linear regression

### 模型
$y=Xw + b + \sigma$ # X: 行为样本，列为特征

### 损失函数
$MSE = L(w, b) = \frac{1}{n}\sum \frac{1}{2}(w^Tx^{(i)} + b - y^{(i)})^2$

（使用MSE的原因：（1）随便选，结果发现有效，w/b效果很好；（2）从理论解的角度，噪声$\sigma$属于正态分布，使用极大似然估计求log得MSE）

### 优化算法
梯度下降SGD->小批量随机梯度下降 minibatch stochastic gradient descent
- 超参数：批量大小batch size；学习率 learning rate。

### 其他概念
全连接层fully-connected layer / 稠密层 dense layer = 每个输入特征都与输出特征相连

层数 = 神经网络的特征层数。一般不算输入层，但是算输出层（等价于计算中间的w/b层数）。线性回归是单层神经网络。

## softmax回归（用于分类问题）

### 分类问题标签定义
与线性回归的预测连续数值所不同，在分类问题中我们希望模型计算出归属于哪一个离散的类别。（实际上我们模型输出的依然是连续的数值，是多个类别的预测概率数值）

为了套用线性回归模型，我们可以为每个类别设置一个整数123...，然后将问题转换为回归问题。但是这样做是有问题的（why？）

通用做法：使用one-hot encoding，模型输出是一个向量，元素数量 == 类别数。标签设置为(1,0,0) | (0,1,0) | (0,0,1)。我们希望模型也输出(1,0,0)来实现类别预测，每个元素代表该类别的概率。

### 模型/网络架构

数据集具有n个样本，d个特征，输出为q个类别的概率大小。

1. 输出q个类别$o = Wx + b$：使用单层神经网络，但是比线性回归多一些输出的神经元，就可以实现q个数值输出
2. softmax运算$y' = softmax(o), y'_j = \frac{exp(o_j)}{\sum_{k=1}^{q} exp(o_k)}$：o是未规范的数值，我们希望输出的是概率，因此使用softmax进行归一化。（不用softmax：o没有概率的含义，后面交叉熵损失的输入就不是概率了；而且oj可能是负数，作为log输入是不行的）
3. 矢量化的SGD $O = XW + b, Y' = softmax(O)$: n x d, d x q --> n x q

### 损失函数（交叉熵损失的推导）
每个样本i都有一个真实的标签，比如$y^(i)_1$对应类别猫。我们的目标是让n个样本，每个样本的真实标签$y^(i)_j$的预测概率尽量大。

首先将n个样本的概率联乘（先不管具体的j）：

$P(Y|X) = \prod_{i=1}^n P(y^(i) | x^(i) $

使用极大似然估计：

$-log P(Y|X) = \sum_{i=1}^n -log P(y^{(i)} | x^{(i)}) = \sum_{i=1}^n l(y^{(i)}, y'^{(i)})$

对于样本i来说，我们关注的就是真实标签k的概率，希望它的概率尽可能大，所以本质上每个样本对应的l，就是j下标的预测概率大小。因为真实标签的元素为one-hot，所以可以一起写成下面的形式：（不等于k的分量y_j=0,该项不存在了）

$l(y, y') = - \sum_{j=1}^q y_j log y'_j$

极限情况就是$y'_j=1$,那么log=0，那么损失函数=0，最小了。

softmax数学上正确，但是存在元素过大/过大，导致exp后数值上溢或者下溢的问题。(待总结：-max，exp+log，实现)


（还可以从信息论的角度来思考，具体见[d2l-softmax](https://zh.d2l.ai/chapter_linear-networks/softmax-regression.html)。大致理解是，熵$H[P]=\sum_j -P(j) log P(j)$代表信息量的大小，其中log代表事件j的诧异程度，所以总体代表诧异的期望。越诧异，代表分布越乱，难以预测。那么交叉熵，就是主观概率分布为Q，观察概率P分布生成的数据时，的诧异程度。交叉熵越大代表越诧异，也就是P和Q差异很大，不好。）

总结：交叉熵代表真实概率分布和预测概率分布之间的差异，差异越大交叉熵越大，所以我们降低损失/交叉熵，就会让预测分布和真实分布越来越接近。极大似然从概率最大化的角度推导，信息论从分布差异/诧异程度的角度来理解。

## 多层感知机 MLP

### 与softmax回归的区别：非线性
softmax回归要求输入和输出之间是线性关系。线性关系/正相关关系是我们人类理解世界的方式，即使是非线性我们一般也通过特征工程，提取合适的特征，使特征&输出是线性关系/正相关关系（比如$y=x^2$构造特征$|x|$,比如BCI中提取左右脑能量差异作为特征）。但是真实世界大多数都是非线性问题，依靠人的特征工程-强行变为线性，不仅费时费力，而且可能还做不到。

### MLP结构
1. 多个隐藏层：堆叠多个隐藏层，就将网络从softmax变为了multilayer perceptron (MLP)了。单层MLP==1层隐藏层+1层输出层。
2. 非线性激活函数 activation function $\sigma$：直接堆叠多层，依然是线性模型。因为$O=(XW+b)W1+b1$可以退化为单层神经网络softmax。所以要在中间层输出加上非线性的激活函数：

$H = \sigma(XW1 + b1)$

$O = HW2 + b2$

### MLP理解
理论上单隐藏层MLP可以表示任意函数（想象ReLU，作为一个折线，而$XW+b$看作是旋转+伸缩变换，那么多个ReLU加在一起，就可以模拟任意曲率/方向的非线性变化的离散过程）。但是尝试用单隐藏层、很胖/广的MLP来解决所有问题是不行的，研究者发现使用更深而不是更广的网络，更容易逼近许多函数。

一般隐藏层的单元为2的次幂，因为内存的分配/寻址高效。

$ReLU(x) = max(x, 0)$

保留正元素，丢弃所有的负元素。

$sigmoid(x) = \frac{1}{1 + exp(-x)}$

来自于生物中的阈值单元，在将输入压缩到(0, 1)范围内。输入在0附近时，近似于线性变换。

## 经验总结
### 案例实践->感悟/理解
《线性回归》“即使我们保证模型是完美的，使用梯度下降也无法使损失函数真正达到最小值。因为算法会使得每个epoch缓慢收敛，但是不能在有限步内一定达到最小值。对深度神经网络来说，损失平面上通常包含多个最小值。深度学习实践者很少会花费大力气去寻找一组超参数，使得训练集上的损失达到最小。事实上，更难做到的是找到一组参数，这组参数能够让我们在未见过的数据上实现较低的损失，这一挑战叫泛化generalization”。
- 我总是问“怎么证明这一组参数就是最优的”，实际上不需要，因为我们无法找到全局最优解，只需要找到“足够优”的解就好了。足够优的标准/目标是达到实际使用需求的水平，或者是比现有的更好；并不需要找出当前模型的遍历最优解。
- 框架比调超参数更加重要。花大量的时间遍历超参数有可能能够得到一个sota结果，但是耗时耗力，经验不可迁移；我们的目标应该是找到一个网络框架，使用合理的超参数（设一个常见值，比如层数=10，设1/69则是比较奇怪的不常见值），就能够达到（“足够好”的效果-1%）内。1%是因为调整超参数本身可能有1%的变化，说明我们的结构能够达到sota。

### nan出现的原因
参数出现nan，想象中是因为梯度过大导致参数w=inf-inf=nan的情况，实际上计算是离散的过程，是因为loss分量出现inf，loss.sum/mean=nan，导致梯度nan，导致w/b step以后也是nan
